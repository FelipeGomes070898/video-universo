# video-universo

Pipeline e padrão do documentário "Universo" (YouTube, 16:9).

- `BRIEF.md`: padrão visual, de áudio, QC e entrega.
- `HANDOFF.md`: estado atual e próximo passo.
- `pipeline/`: scripts de render, narração, thumbnail, QC e upload.
- `pipeline/channel/` + `pipeline/channel.py`: análise do canal do YouTube (somente leitura) e relatório estratégico antes de cada vídeo.
- `analises/`: relatórios estratégicos e histórico agregado (`historico/`).
- `entregas/`: vídeos prontos, por versão.
